# cafe-java

## Описание проекта:
Система управления приготовлением блюд в кафе — это backend-приложение на Java Spring Boot для управления процессом приготовления блюд и складом ингредиентов в кафе.
Система ориентирована на учёт рецептов, ингредиентов, партий поставок и контроль сроков годности.

## Сущности:
1. Dish - блюдо, которое готовится в кафе.
2. Recipe - рецепт блюда.
3. Ingredient - тип ингредиента (например: молоко, мука, курица).
4. IngredientStock - конкретная партия ингредиента на складе со сроком годности и количеством.
5. RecipeIngredient - хранит количество ингредиента, необходимое для приготовления блюда.

## Основная функциональность:
1. Хранение блюд и их рецептов
2. Учёт ингредиентов
3. Учёт партий ингредиентов (с датами поставки и сроком годности).
4. Связь рецептов с ингредиентами и количеством.
5. Проверка доступности блюда для приготовления.
6. Контроль просроченных партий.
